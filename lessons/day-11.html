Day 11: Geschenke: the dative case

dem, der, dem, den · helfen, gefallen, gehören · mir, dir, ihm

▶ Start this lesson (with audio)

What you learn today

  • Use the dative for the indirect object (to whom?)
  • Know the dative articles: dem, der, dem, den + n
  • Use dative verbs: helfen, danken, gefallen, gehören, schmecken, passen
  • Use dative pronouns: mir, dir, ihm, ihr, uns, euch, ihnen, Ihnen

Grammar

The dative case (indirect object)

dem, der, dem, den + n · wem? · mir, dir, ihm …

Summary

  • Dative = to/for whom (wem?)
  • dem / der / dem / den + n · einem / einer / einem
  • helfen, danken, gefallen, gehören, schmecken, passen + Dativ
  • mir, dir, ihm, ihr, ihm, uns, euch, ihnen, Ihnen · Mir ist kalt.
🇩🇪 Culture tip: German birthday etiquette: wish „Alles Gute zum Geburtstag!“ only on or after the day. Presents are opened right away, in front of the giver – and flowers are given in odd numbers, without the paper.
